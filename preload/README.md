Content files the game reads, downloaded ahead of time: `startup.json` is what the menus need,
awaited behind the startup loading screen; `game.json` is everything a game needs (sounds, piece,
terrain, battle and town art), downloaded in the background while the player is in the menus — a
game started before it has all arrived waits for the rest on its loading screen.
Generated by `node tools/record-preload.mjs` against a running site — regenerate after changing
which content the game loads. A file missing from these lists still works; it is just fetched
synchronously at the moment the game asks for it.
