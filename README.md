# Pieces of the Dynasties — Tamerlane test

Play in the browser: **https://kimplaybit.github.io/Pieces-of-the-dynasties-tamerlane-test/**

A battle-only test build: a full chess army against the Tamerlane army. Pick the AI's strength
(Easy to Expert, ~2200 Elo), then play as Chess or as Tamerlane — or Hotseat for two players on one
screen. Right-click any piece to see how it moves.

Works best in a desktop browser (Firefox, Chrome, Edge). The first load downloads about 30 MB.

This repository holds the built site only; it is published with GitHub Pages.
